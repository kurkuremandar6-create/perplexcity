Step 1

Calculate token surprises

Convert each token probability into surprise: -ln(P).

Step 2

Calculate average surprise

Divide the total negative log likelihood by token count N.

Average NLL = Sum(-ln(P)) / N
Step 3

Calculate perplexity

Exponentiate the average surprise to return from log space.

Perplexity = exp(Average NLL)

Perplexity measures how surprised a language model is by a sequence. Lower perplexity generally means the model considers the sequence more predictable.

About Perplexity Explorer

Perplexity Explorer is a client-side educational playground designed to demystify how autoregressive causal language models score text, assign token probabilities, and compute perplexity.

How the real calculation works

1. Your sentence is encoded with the GPT-2 BPE tokenizer, and token 50256 (<|endoftext|>) is prepended as the initial context token.
2. A single forward pass through Xenova/distilgpt2 (quantized with dtype: "q8") produces logits of shape [1, sequence_length, 50257].
3. For each sentence token at index i, a numerically stable log-softmax over the logits at position i - 1 gives its exact probability P and negative log probability -ln(P).
4. Perplexity is computed in log space: exp((1/N) * sum(-ln(P))), avoiding overflow from multiplying inverse probabilities.

Privacy & Architecture

All tokenization, tensor math, and ONNX inference run directly inside your browser using Transformers.js v3. After downloading the model files from Hugging Face, no prompt text or results leave your device.
